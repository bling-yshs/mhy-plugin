# 原神委托领奖提醒

在需要接收提醒的群内发送 `#开启原神委托提醒`。每人只保留最后开启的群，再次开启会替换原来的机器人和群。在任意群发送 `#关闭原神委托提醒` 会直接删除本人的订阅记录。订阅保存在 SQLite，重启后继续生效。

机器人进程采用北京时间，通过云崽调度器以 `0 0 22 * * *` 每天 22:00 触发一次。提醒直接从 SQLite 读取发送者及其当前启用的 `Users.games.gs.uid`，精确匹配本人关联账号的 CK。开启时缺少当前 UID 或对应 CK 会提示先绑定；切换 UID 后，之后的检查使用最新启用角色；执行时绑定失效则记日志并跳过。

使用实时 `dailyNote` 响应的 `data.is_extra_task_reward_received`：严格为 `false` 时加入提醒名单；为 `true` 时保持静默。委托尚未全部完成也会提示。检查完成后，按机器人和群汇总名单，每群发送一条消息，集中 @ 未领奖用户并列出各自 UID。

订阅表记录每人的最后成功处理时间：查询确认奖励已领取，或未领奖提醒发送成功后更新。表中每一行代表开启的订阅，每天 22:00 读取全部订阅进行检查。查询或发送失败只记日志，调度器无启动补跑和当天失败自动重试。每轮使用开始查询时的订阅和当前 UID，执行期间修改设置在下一次检查时生效。更换接收群保留最后成功处理时间；关闭会连同成功时间删除订阅，再次开启时创建新记录。

停止机器人，在插件目录运行 `pnpm install`、`pnpm build`，然后启动。启动时自动备份并执行待完成的数据库迁移，保留开启的订阅，重命名成功时间列并移除开关列。详细步骤见 [数据库结构迁移](database-migrations.md)。源码与编译产物需一同部署。
