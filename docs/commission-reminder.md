# 原神委托领奖提醒

在需要接收提醒的群内发送 `#开启原神委托提醒`。每人只保留最后开启的群，再次开启会替换原来的机器人和群。在任意群发送 `#关闭原神委托提醒` 可以关闭本人的唯一订阅。订阅保存在 SQLite，重启后继续生效。

机器人进程采用北京时间，通过云崽调度器以 `0 0 23 * * *` 每天 23:00 触发一次。提醒直接从 SQLite 读取发送者及其当前启用的 `Users.games.gs.uid`，精确匹配本人关联账号的 CK。开启时缺少当前 UID 或对应 CK 会提示先绑定；切换 UID 后，之后的检查使用最新启用角色；执行时绑定失效则记日志并跳过。

使用实时 `dailyNote` 响应的 `data.is_extra_task_reward_received`：严格为 `false` 时加入提醒名单；为 `true` 时保持静默。委托尚未全部完成也会提示。检查完成后，按机器人和群汇总名单，每群发送一条消息，集中 @ 未领奖用户并列出各自 UID。

每人每天仅检查一次，无启动补跑和当天失败自动重试。接口异常、字段缺失、发送失败只记录日志，其余用户继续检查。每轮使用开始查询时的当前 UID，执行期间切换 UID 或解绑，下一次检查时生效。检查期间关闭订阅或更换接收群后，过期结果不会发送。当天更换接收群或重新开启会保留最后检查日期，次日使用最新位置。

部署时运行 `pnpm build` 并重启机器人，再在群内开启。源码与编译产物需一同部署。
