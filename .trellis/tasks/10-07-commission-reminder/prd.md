# 原神每日委托领奖提醒

## 目标与依据

每天北京时间 23:00，在最后开启提醒的群中 @ 本人，提醒当前启用原神 UID 领取每日委托奖励。用户已逐项确认本方案并明确授权实施。机器人进程使用北京时间；数据直接读取 SQLite。参考 Users.games.gs.uid 角色选择以及真实 dailyNote 的布尔字段 data.is_extra_task_reward_received。

## 需求

- #开启原神委托提醒，为发送者保存唯一长期订阅；再次开启替换机器人和群，重启后继续生效。任意群 #关闭原神委托提醒 可以关闭本人订阅。
- 提醒 cron 为 0 0 23 * * *；签到一并改为 0 2 0 * * *，每天 00:02 直接触发。移除每分钟判时逻辑，无启动补跑。
- 开启时校验当前 UID 和对应本人 CK，缺失时提示绑定后再开启。
- 只查询实时启用、属于本人绑定米游社账号且有 CK 的 UID；缺失时跳过。
- 成功响应领取状态严格为 false 时，发送含 @、UID 和领奖提示的群消息；已领取或接口异常时群内静默。
- 每个订阅当天仅检查一次，查询或发送失败记录日志并隔离其它订阅。
- 在途关闭、切换 UID 或解绑后阻止过期提醒。

## 验收

- [ ] 群内开启／关闭、私聊限制、重复开启去重及持久化。
- [ ] 两项每日 cron 直接注册执行函数、当天防重、次日执行。
- [ ] UID 切换后只查询新 UID，无当前或非本人 UID 时跳过。
- [ ] false 发送，true、异常字段、错误响应或网络失败静默。
- [ ] 每人只保留最后接收位置，任意群关闭本人提醒；支持在途关闭、换群、UID 切换和解绑。
- [ ] 类型、lint、格式、构建与离线回归通过。

## 范围

原神每日委托奖励提醒；复用既有请求、账号、设备、调度和 SQLite，不新增依赖。其它游戏、自动领奖、全天重试、自动订阅和体力图片改动留待后续需求。
