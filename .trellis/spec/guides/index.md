## 通用检查

- 先用 `rg` 搜索同类端点、字段和状态转换，再决定代码归属。
- 把外部响应、内部凭据模型、持久化记录和用户消息视为不同契约。
- 对参考仓库中的行为标注来源与验证状态，协议结论需要真实响应或官方资料支撑。
- 涉及 Token、Cookie、设备信息和 HTTP 历史时，先确认数据的保存位置与暴露范围。
